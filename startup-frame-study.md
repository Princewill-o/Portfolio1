# Startup study — supplied PS5 frame archive

All 108 supplied JPG frames were reviewed in six full contact sheets and processed for per-frame mean colour and image differences. The archive has no timing metadata. Estimated timestamps use about four samples per second, consistent with the supplied 27.098-second MP4; frame order is authoritative. This is a study of the supplied samples, not every encoded frame of the original video.

The ordinary cold opening uses 6,600 ms for the logo phase and 6,900 ms for the atmosphere phase. The ready screen waits for the visitor. Loading tracks actual cover-image readiness and retains error recovery. Skip remains available; reduced motion bypasses the long animated intro.

PS App branding uses the user's supplied screenshot, framed with an SVG viewport crop rather than repainting it. The startup mark uses the user's second supplied image. The ready screen is adapted for keyboard/mouse rather than displaying a controller or the reference video's unrelated profile/game data.

The recreation follows the observed timing and visual hierarchy; it is not a pixel-for-pixel video reproduction. All project tiles are Princewill's portfolio entries. See startup-frame-analysis.csv for every supplied frame's phase and measurements.
